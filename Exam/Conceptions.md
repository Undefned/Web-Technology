<a id="1-определение-веб-сайта"></a>
## 1. Определение веб-сайта, передача и отображение

**Веб-сайт** — файлы (HTML, CSS, JS) в интернете по URL.

**Файлы:**
- **HTML** — структура (что на странице)
- **CSS** — внешний вид (как выглядит)
- **JS** — поведение (что делает)

**Процесс отображения:**
1. Браузер отправляет запрос на сервер
2. Сервер возвращает HTML-страницу
3. Браузер парсит HTML, строит DOM-дерево
4. Загружает CSS, применяет стили
5. Выполняет JS-скрипты
6. Отрисовывает готовую страницу

**Браузер = конструктор**: получает код, собирает из него готовую страницу.

---

<a id="2-протокол-http"></a>
## 2. Протокол HTTP и передача гипертекста

**HTTP** — правила общения браузера (клиента) и сервера.

**Особенности:**
- Работает по схеме "запрос → ответ"
- Stateless (без состояния) — нужны cookies для сессий
- Текстовые команды, читаемые человеком

**Пример запроса:** `GET /page.html HTTP/1.1`
**Пример ответа:** `200 OK` с данными

**Коды статуса:**
- **2хх** — успех (200 OK)
- **3хх** — перенаправление (301 Moved)
- **4хх** — ошибка клиента (404 Not Found)
- **5хх** — ошибка сервера (500 Internal Error)

**HTTPS** = HTTP + шифрование TLS/SSL.
**Гипертекст** = текст со ссылками (HTML документы).

<a id="3-типографика-и-верстка"></a>
## 3. Типографика, символы, правила вёрстки

**Экран ≠ бумага:** пиксели, свечение, адаптивность, масштабирование.

**Единицы в CSS:**
- **px** — пиксели (базовые)
- **em** — относительно размера родителя
- **rem** — относительно корневого элемента
- **%** — проценты от размера родителя
- **vw/vh** — от ширины/высоты окна

**Спецсимволы (HTML entities):**
- `&lt;` = <
- `&gt;` = >
- `&amp;` = &
- `&nbsp;` = неразрывный пробел
- `&copy;` = ©
- `&#128512;` = 😀 (emoji)

**Правила типографики:**
1. Семантические теги (`<h1>`, `<p>`, `<ul>`, `<blockquote>`)
2. Оптимальная ширина строки: 45-75 символов
3. Line-height: 1.5× для читаемости
4. Выравнивание по левому краю (не по ширине)
5. Достаточный контраст текста и фона
6. Системные отступы (кратные 8px)
7. Правильные кавычки: «ёлочки» для русского

<a id="4-svg-формат"></a>
## 4. Формат SVG

**SVG** — векторная графика в формате XML. Не пиксели, а команды (фигуры, пути).

**Особенности:**
- Масштабируется без потери качества
- Маленький вес для иконок, лого
- Можно редактировать кодом
- Стилизуется и анимируется CSS/JS
- Чёткий на любых экранах

**Пример (круг):**
```svg
<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" fill="green"/>
</svg>
```

**Оптимизация:** Убрать мусор, сократить числа (инструмент SVGO).

**Встраивание:**
1. `<img src="icon.svg">` — просто, но нельзя менять стили
2. **Инлайн (код в HTML)** — полный контроль, можно менять цвет через CSS (`fill: currentColor`)

<a id="5-форматы-изображений"></a>
## 5. Форматы изображений в вебе

**Как выбирать:**

**JPG** — для фотографий. Сжатие с потерями, маленький вес.

**PNG** — для графики с прозрачностью. Без потерь, но тяжёлый.

**GIF** — для простых анимаций (256 цветов).

**WebP** — современный формат. Меньше JPG/PNG при том же качестве. Поддерживает прозрачность и анимацию.

**AVIF** — самый новый, ещё лучше сжатие.

**Современный подход:**
```html
<picture>
  <source srcset="image.webp" type="image/webp">
  <img src="image.jpg" alt="..." loading="lazy">
</picture>
```
Браузер выберет лучший поддерживаемый формат.

<a id="6-семантика-верстки"></a>
## 6. Семантика вёрстки и HTML5

**Семантика** — использование тегов по смыслу, а не только для вида.

**Семантические теги:**
- `<header>` — шапка
- `<nav>` — навигация
- `<main>` — основное содержание
- `<article>` — самостоятельная статья
- `<section>` — тематический раздел
- `<aside>` — боковая панель
- `<footer>` — подвал
- `<figure>` + `<figcaption>` — изображение с подписью

**Преимущества:**
1. Лучше для доступности (скринридеры)
2. Лучше для SEO
3. Удобнее для разработки
4. Браузеры дают стили по умолчанию

**Итог:** Делать документ, а не просто картинку из блоков.

<a id="7-доступная-навигация"></a>
## 7. Доступная навигация

**Цель** — чтобы все пользователи могли перемещаться по сайту.

**Ключевые элементы:**

1. **`<nav>` + списки (`<ul>`)** — правильная разметка меню
2. **«Пропустить навигацию»** — скрытая ссылка для перехода к контенту
3. **Логичные заголовки** — `<h1>`-`<h6>` для навигации скринридером
4. **Чёткий фокус** — видимое выделение при Tab
5. **ARIA-атрибуты** — дополнительные подсказки для скринридеров
6. **Правильные элементы** — `<a>` для ссылок, `<button>` для действий
7. **Большие цели** — кликабельные области минимум 44×44px
8. **Альтернативы** — поиск, карта сайта, «хлебные крошки»

<a id="8-динамика-контента"></a>
## 8. Динамика контента сайта

**Динамика** — изменения на странице без перезагрузки.

**Технологии:** JavaScript, CSS-анимации.

**Типы динамики:**

1. **От пользователя** — клики, ввод, наведение
   - Раскрытие блоков
   - Сортировка товаров
   - Валидация форм

2. **Асинхронная загрузка (AJAX/Fetch)** — обновление части страницы
   - Бесконечная лента
   - Добавление в корзину
   - Живые уведомления

3. **Клиентский рендеринг (SPA)** — JS рисует весь интерфейс
   - React, Vue, Angular
   - Быстрые переходы
   - Медленная первая загрузка

4. **Серверный рендеринг (SSR)** — сервер генерирует HTML
   - Next.js, Nuxt.js
   - Лучше для SEO

5. **WebSockets/SSE** — живое обновление
   - Чаты
   - Финансовые тикеры

<a id="9-дизайн-концепция"></a>
## 9. Дизайн-концепция сайта

**Дизайн-концепция** — основная идея, определяющая стиль сайта.

**Из чего состоит:**
- Цвета и шрифты
- Композиция
- Эмоциональный посыл
- Метафора (лейтмотив)

**Подходы:**

1. **От бренда** — продолжение фирменного стиля (Coca-Cola)
2. **От аудитории** — под потребности пользователей
   - Пожилые → крупный текст, контраст
   - Молодёжь → ярко, динамично
3. **От продукта** — отражает суть
   - Эко-бренд → природные цвета
   - Технологии → тёмная тема, неон
4. **От трендов** — современные стили
5. **От истории** — сайт как повествование

**Примеры:**
- **Apple** — минимализм, фокус на продукте
- **Nike** — энергия, движение, спорт
- **Notion** — чистый холст для работы

**Итог:** Концепция делает сайт цельным, узнаваемым и соответствующим цели.

<a id="12-адаптивный-дизайн"></a>
## 12. Адаптивный дизайн сайта

**Суть:** Сайт подстраивается под любой экран.

**Точки слома (breakpoints):**
- Контрольные ширины, где меняется вёрстка
- Обычно: 576px, 768px, 992px, 1200px

**Как перестраивается:**
1. Перетекание — элементы сжимаются
2. Смена колонок — с 3 на 2, с 2 на 1
3. Скрытие меню — гамбургер на мобильных
4. Адаптация картинок — `max-width: 100%`

**Подходы:**
- **Mobile First** — сначала мобильные, потом добавки для ПК (лучше)
- **Desktop First** — сначала ПК, потом упрощение для мобильных

---

<a id="13-адаптивная-верстка"></a>
## 13. Адаптивная вёрстка

**Технологии:**
1. **Медиазапросы** — `@media (min-width: 768px)`
2. **Относительные единицы:**
   - `%` — проценты от родителя
   - `rem` — от размера корневого шрифта
   - `vw` — от ширины окна
3. **Flexbox/Grid** — для сеток
4. **Гибкие картинки** — `max-width: 100%`

**Подходы:**
- **Mobile First** — старт с мобильных, медиазапросы `min-width`
- **8px grid** — все отступы кратны 8px

<a id="2-плохой-дизайн"></a>
## 2. Плохой веб-дизайн

**Признаки:**
- Перегруженная навигация — слишком много пунктов
- «Стена текста» — сплошной текст без абзацев

<a id="3-композиция-иерархия"></a>
## 3. Композиция и визуальная иерархия

**Композиция** — как элементы расположены на странице.

**Визуальная иерархия** — как элементы организованы по важности.

**Как создать иерархию:**
1. **Размер** — крупнее = важнее
2. **Цвет** — ярче/контрастнее = важнее
3. **Расположение** — выше/в центре = важнее
4. **Шрифт** — жирный/крупный = важнее
5. **Пространство** — больше воздуха вокруг = важнее

**Цель:** Направить взгляд пользователя к главному.

<a id="4-траектории-восприятия"></a>
## 4. F- и Z-образные траектории

**F-паттерн:**
- Для текстовых страниц (блоги, статьи)
- Глаз сканирует: сверху → вниз, слева → направо
- Важное ставить в начале строк и абзацев

**Z-паттерн:**
- Для лендингов, простых страниц
- Глаз движется зигзагом: левый верх → правый верх → диагональ → левый низ → правый низ
- Кнопки действий в точках «остановки»

**Композиционные паузы** — пустое пространство для отдыха глаза.

**Бенто-дизайн** — аккуратные геометрические блоки.

**Статика** — симметрия, спокойствие.

**Динамика** — асимметрия, энергия.

<a id="5-цвет-в-дизайне"></a>
## 5. Цвет в управлении вниманием

**Функции цвета:**
1. **Акценты** — выделить важное (кнопки)
2. **Группировка** — связать похожие элементы
3. **Статусы** — показать состояние (ошибка, успех)
4. **Эмоции** — создать настроение

**Контраст** — критически важен:
- Для читаемости текста
- Для доступности (WCAG стандарты)
- Для выделения важного

**Ошибка:** Серый текст на белом фоне — плохо читается.

<a id="6-шрифты-иерархия"></a>
## 6. Шрифты и типографическая иерархия

**Шрифтовые пары:**
- Акцидентный (яркий, для заголовков) + нейтральный (для текста)
- Пример: Playfair Display (заголовки) + Roboto (текст)

**Типографическая иерархия** — различие заголовков и текста:
- Размер (крупнее = важнее)
- Начертание (жирный, курсив)
- Цвет
- Отступы

**Шрифт задаёт характер:**
- Без засечек — современно, минималистично
- С засечками — традиционно, серьёзно
- Рукописные — креативно, неформально

**Для читаемости:**
- Длина строки: 45-75 символов
- Межстрочный интервал: 1.5× от размера шрифта

<a id="7-необычные-формы"></a>
## 7. Необычные формы в интерфейсе

**Зачем нужны:**
1. **Выделение бренда** — делают уникальным
2. **Направление взгляда** — ведут по странице
3. **Создание эмоций** — форма = настроение
   - Округлые → мягкие, дружелюбные
   - Угловатые → строгие, деловые
4. **Создание ритма** — повтор форм

**Повторение одной формы** в разных местах создаёт систему.

**Безопасно:** Простые геометрические формы.

**Рискованно:** Слишком сложные формы могут мешать.

<a id="8-анимация-в-интерфейсе"></a>
## 8. Анимация в интерфейсе

**Задачи анимации:**
1. **Обратная связь** — показать, что действие принято
2. **Ориентация** — показать, откуда пришли/куда идём
3. **Визуализация изменений** — плавные переходы
4. **Скрытие задержек** — пока грузится, что-то происходит

**Хорошая анимация:**
- Быстрая (200-500 мс)
- Осмысленная (несёт пользу)
- Плавная

**Плохая анимация:**
- Медленная (мешает)
- Отвлекающая (слишком заметная)
- Бесполезная

**В Figma:**
- **Instant** — мгновенная смена
- **Smart Animate** — плавный переход между состояниями
