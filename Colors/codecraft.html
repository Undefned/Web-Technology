Шрифтовые комбинации для IT‑проектов

Для заголовков (Display)

JetBrains Mono

Моноширинный, но современный. Идеален для кода и IT-заголовков.

font-family: 'JetBrains Mono', monospace;
Manrope

Минималистичный гротеск с отличной читаемостью на экранах.

font-family: 'Manrope', sans-serif;
Montserrat

Геометрический, чёткий, современный. Хорош для крупных заголовков.

font-family: 'Montserrat', sans-serif;

Для основного текста (Body)

Inter

Специально создан для экранов. Лучший выбор для основного текста в интерфейсах.

font-family: 'Inter', sans-serif;
System Stack

Использует системные шрифты (Segoe UI / SF Pro). Быстрая загрузка, оптимизировано для ОС.

font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
