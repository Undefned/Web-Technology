Общие советы для всех компаний.

Подготовка к собеседованию:

1. Алгоритмы — 30% времени

  • LeetCode Easy/Medium (50-100 задач)
  • Структуры: HashTable, Lists, Trees, Graphs
  • Сложность: O(n), O(log n), O(n log n)

2. System Design — 30% времени

  • Спроектировать систему (URL shortener, chat, social network)
  • Масштабирование (sharding, replication, caching)
  • Балансировка, очереди, микросервисы

3. .NET — 25% времени

  • Коллекции, LINQ, async/await
  • GC, память, производительность
  • ASP.NET Core, EF Core, DI

4. SQL — 10% времени

  • Сложные запросы (JOIN, GROUP BY, оконные функции)
  • Индексы, оптимизация

5. Soft Skills — 5% времени

  • Расскажите про свои проекты
  • Почему вы хотите работать в этой компании
  • Ваши достижения (кейсы)

Практический чек-лист:

  • ☐ Пройти 50 задач на LeetCode
  • ☐ Написать REST API + БД + Docker
  • ☐ Почитать про System Design (YouTube, книги)
  • ☐ Подготовить 3 проекта для рассказа
  • ☐ Почитать про компанию (продукты, технологии)
  • ☐ Потренироваться отвечать на вопросы вслух
