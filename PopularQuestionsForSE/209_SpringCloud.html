☁️ 9. Spring Cloud (микросервисы)

Spring Cloud Netflix — Eureka, Ribbon, Hystrix, Zuul

Набор компонентов для микросервисов (Netflix OSS).

  • Eureka — Service Discovery (регистрация сервисов)
  • Ribbon — клиентский Load Balancer
  • Hystrix — Circuit Breaker
  • Zuul — API Gateway (устарел, теперь Spring Cloud Gateway)
// Eureka Server
@SpringBootApplication
@EnableEurekaServer
public class DiscoveryService {
    public static void main(String[] args) {
        SpringApplication.run(DiscoveryService.class, args);
    }
}

// Eureka Client
@SpringBootApplication
@EnableDiscoveryClient
public class UserService {
    public static void main(String[] args) {
        SpringApplication.run(UserService.class, args);
    }
}

// Ribbon — балансировка на клиенте
@Configuration
public class RibbonConfig {
    @Bean
    @LoadBalanced
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}

@Service
public class OrderService {
    @Autowired
    private RestTemplate restTemplate;
    
    public User getUser(Long id) {
        // user-service — имя сервиса в Eureka
        return restTemplate.getForObject("http://user-service/users/" + id, User.class);
    }
}

// Hystrix — Circuit Breaker
@Service
public class OrderService {
    @HystrixCommand(fallbackMethod = "getDefaultUser")
    public User getUser(Long id) {
        return restTemplate.getForObject("http://user-service/users/" + id, User.class);
    }
    
    public User getDefaultUser(Long id) {
        return new User(id, "Default User");
    }
}

В C# аналог — Service Discovery (Consul, Eureka) + Polly + Ocelot/YARP.

Spring Cloud Config — централизованная конфигурация

Config Server — централизованное хранение конфигураций для всех сервисов.

// Config Server
@SpringBootApplication
@EnableConfigServer
public class ConfigService {
    public static void main(String[] args) {
        SpringApplication.run(ConfigService.class, args);
    }
}

// application.yml (Config Server)
server:
  port: 8888
spring:
  cloud:
    config:
      server:
        git:
          uri: https://github.com/myorg/config-repo
          default-label: main

// Файл в Git-репозитории: user-service.yml
user:
  message: "Hello from Config Server"
  feature:
    enabled: true

// User Service — получает конфигурацию
@SpringBootApplication
@EnableDiscoveryClient
public class UserService {
    public static void main(String[] args) {
        SpringApplication.run(UserService.class, args);
    }
}

// bootstrap.yml (User Service)
spring:
  cloud:
    config:
      uri: http://config-server:8888
      name: user-service

// Использование конфигурации
@Component
@ConfigurationProperties(prefix = "user")
public class UserConfig {
    private String message;
    private Feature feature;
    // getters/setters
}

@Service
public class UserService {
    @Autowired
    private UserConfig config;
    
    public void printConfig() {
        System.out.println(config.getMessage());  // "Hello from Config Server"
    }
}

В C# аналог — нет (можно использовать Consul KV, etcd, или самому сделать).

Spring Cloud Bus — обновление конфигурации на лету

Spring Cloud Bus — обновление конфигурации всех сервисов без перезапуска.

  • Использует брокер сообщений (RabbitMQ, Kafka)
  • При изменении конфигурации в Git — отправляет событие
  • Все сервисы получают событие и обновляют конфигурацию
// Подключение
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-bus-amqp</artifactId>
</dependency>

// В каждом сервисе
@RefreshScope  // позволяет обновлять бины
@Component
@ConfigurationProperties(prefix = "user")
public class UserConfig {
    private String message;
    // getters/setters
}

// Endpoint для обновления (отправляет событие в Bus)
// POST /actuator/busrefresh
// или для конкретного сервиса: POST /actuator/busrefresh/order-service

В C# аналог — нет (можно через Configuration Refresh + SignalR/Service Bus).

Spring Cloud Sleuth — распределённая трассировка

Sleuth — добавляет trace ID и span ID во все логи и HTTP-заголовки.

// Подключение
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-sleuth</artifactId>
</dependency>

// Использование — логи автоматически получают traceId/spanId
log.info("User service called");  // [user-service, 2a3b4c5d, 6e7f8g9h, true]

// Передача между сервисами
// User Service → Order Service
// Заголовки: X-B3-TraceId, X-B3-SpanId, X-B3-Sampled

// Интеграция с Zipkin
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-sleuth-zipkin</artifactId>
</dependency>

// application.yml
spring:
  zipkin:
    base-url: http://zipkin-server:9411

В C# аналог — OpenTelemetry + Jaeger/Zipkin.
