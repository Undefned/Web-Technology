⚡ 8. Reactive Stack — Spring WebFlux (чего нет в C#)

Spring WebFlux vs Spring MVC — разница

Spring MVC — блокирующий (Servlet API). Spring WebFlux — реактивный (non-blocking).

ХарактеристикаSpring MVCSpring WebFlux
АрхитектураServlet API (блокирующий)Reactive Streams (non-blocking)
СтекTomcat, JettyNetty, Undertow
МодельОдин поток на запросСобытийно-ориентированная
Подходит дляCPU-bound, традиционные приложенияIO-bound, высоконагруженные системы
// Spring MVC — блокирующий контроллер
@RestController
public class UserController {
    @GetMapping("/users")
    public List<User> getUsers() {  // блокирует поток до окончания
        return userService.findAll();  // синхронный вызов
    }
}

// Spring WebFlux — реактивный контроллер
@RestController
public class UserController {
    @GetMapping("/users")
    public Flux<User> getUsers() {  // не блокирует поток
        return userService.findAll();  // возвращает Flux (реактивный)
    }
}
Mono и Flux — что это?

Mono — 0 или 1 элемент. Flux — 0 или N элементов (поток).

  • Mono<T> — аналог Optional или Promise (один результат)
  • Flux<T> — аналог List или Stream (много результатов)
  • Оба из Project Reactor (реализация Reactive Streams)
@RestController
public class ReactiveController {
    
    // Mono — один объект
    @GetMapping("/user/{id}")
    public Mono<User> getUser(@PathVariable Long id) {
        return userService.findById(id);  // Mono<User>
    }
    
    // Flux — поток объектов
    @GetMapping("/users")
    public Flux<User> getUsers() {
        return userService.findAll();  // Flux<User>
    }
    
    // Flux с SSE (Server-Sent Events)
    @GetMapping(value = "/events", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<Event> getEvents() {
        return Flux.interval(Duration.ofSeconds(1))
            .map(i -> new Event("Event " + i));
    }
}

// Работа с Mono и Flux
Mono<User> mono = Mono.just(new User("John"));
Flux<User> flux = Flux.just(new User("John"), new User("Jane"));

// Преобразование
flux.map(User::getName)
    .filter(name -> name.startsWith("J"))
    .collectList()
    .subscribe(names -> System.out.println(names));

// Объединение
Mono.zip(userMono, profileMono, (user, profile) -> new UserDto(user, profile));

В C# аналогов нет напрямую. Ближайшее — IAsyncEnumerable и Task.

// C# — асинхронные потоки
public async IAsyncEnumerable<User> GetUsers() {
    await foreach (var user in _db.Users.AsAsyncEnumerable()) {
        yield return user;
    }
}

// gRPC streaming — аналог Flux
public override async Task GetUsers(Empty request, IServerStreamWriter<User> responseStream, ServerCallContext context) {
    await foreach (var user in GetUsers()) {
        await responseStream.WriteAsync(user);
    }
}
WebClient vs RestTemplate — разница

RestTemplate — синхронный (блокирующий). WebClient — асинхронный (реактивный).

// RestTemplate (синхронный)
RestTemplate restTemplate = new RestTemplate();
User user = restTemplate.getForObject("http://api.example.com/users/1", User.class);

// WebClient (реактивный)
WebClient webClient = WebClient.create("http://api.example.com");

// Блокирующий вызов (превращаем в синхронный)
User user = webClient.get()
    .uri("/users/1")
    .retrieve()
    .bodyToMono(User.class)
    .block();  // блокирует!

// Реактивный вызов (неблокирующий)
Mono<User> userMono = webClient.get()
    .uri("/users/1")
    .retrieve()
    .bodyToMono(User.class);

userMono.subscribe(user -> System.out.println(user));

// Цепочка реактивных вызовов
Mono<UserWithOrders> result = webClient.get()
    .uri("/users/1")
    .retrieve()
    .bodyToMono(User.class)
    .flatMap(user -> webClient.get()
        .uri("/users/" + user.getId() + "/orders")
        .retrieve()
        .bodyToFlux(Order.class)
        .collectList()
        .map(orders -> new UserWithOrders(user, orders))
    );

В C# аналог — HttpClient (синхронный/асинхронный):

// HttpClient — асинхронный
var response = await _httpClient.GetAsync("http://api.example.com/users/1");
var user = await response.Content.ReadFromJsonAsync<User>();

// С цепочкой
var user = await _httpClient.GetFromJsonAsync<User>("http://api.example.com/users/1");
var orders = await _httpClient.GetFromJsonAsync<List<Order>>($"http://api.example.com/users/{user.Id}/orders");
