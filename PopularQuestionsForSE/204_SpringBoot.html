🚀 4. Spring Boot — отличия от ASP.NET Core

@SpringBootApplication — что внутри?

@SpringBootApplication = три аннотации в одной.

@SpringBootApplication
public class MyApp {
    public static void main(String[] args) {
        SpringApplication.run(MyApp.class, args);
    }
}

Эквивалентно:

@Configuration               // XML-конфигурация через Java
@EnableAutoConfiguration     // автоконфигурация по зависимостям
@ComponentScan               // сканирование бинов в текущем пакете
public class MyApp { }

В C# аналог:

// Program.cs в ASP.NET Core
var builder = WebApplication.CreateBuilder(args);
var app = builder.Build();

// Нет одной аннотации — всё в коде
Spring Boot Starter — что это?

Starter — это набор зависимостей для конкретной технологии.

Популярные стартеры:

  • spring-boot-starter-web — REST API, Tomcat, Jackson
  • spring-boot-starter-data-jpa — JPA + Hibernate
  • spring-boot-starter-security — Spring Security
  • spring-boot-starter-test — JUnit, Mockito
  • spring-boot-starter-validation — валидация
  • spring-boot-starter-data-redis — Redis
  • spring-boot-starter-amqp — RabbitMQ
// pom.xml (Maven)
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
    <version>3.1.0</version>
</dependency>

В C# аналоги — пакеты NuGet:

dotnet add package Microsoft.EntityFrameworkCore
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer
Spring Boot Actuator — мониторинг

Actuator — предоставляет эндпоинты для мониторинга приложения.

Основные эндпоинты:

  • /actuator/health — статус приложения (UP/DOWN)
  • /actuator/info — информация о приложении
  • /actuator/metrics — метрики (память, GC, запросы)
  • /actuator/loggers — уровни логирования
  • /actuator/env — переменные окружения
// Подключение (pom.xml)
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-actuator</artifactId>
</dependency>

// application.properties
management.endpoints.web.exposure.include=health,info,metrics
management.endpoint.health.show-details=always

// Кастомный health check
@Component
public class CustomHealthIndicator implements HealthIndicator {
    @Override
    public Health health() {
        if (isReady()) {
            return Health.up().withDetail("status", "OK").build();
        }
        return Health.down().withDetail("status", "Не готов").build();
    }
}

В C# аналог — Health Checks:

builder.Services.AddHealthChecks()
    .AddDbContextCheck<AppDbContext>()
    .AddUrlGroup(new Uri("https://api.example.com"), "External API");

app.MapHealthChecks("/health");
@ConfigurationProperties — маппинг настроек

@ConfigurationProperties — привязывает свойства из application.properties к Java-объекту.

// application.properties
app.name=MyApp
app.version=1.0.0
app.features.cache.enabled=true
app.features.cache.ttl=300

// Класс для маппинга
@ConfigurationProperties(prefix = "app")
@Component
public class AppProperties {
    private String name;
    private String version;
    private Features features = new Features();
    
    // getters/setters
}

public class Features {
    private boolean enabled;
    private int ttl;
    // getters/setters
}

// Использование
@Service
public class MyService {
    private final AppProperties props;
    
    public MyService(AppProperties props) {
        this.props = props;
    }
}

В C# аналог — IOptions<T>:

// appsettings.json
{
    "App": {

// Класс
public class AppOptions {

// Регистрация и использование
services.Configure<AppOptions>(Configuration.GetSection("App"));
var options = serviceProvider.GetService<IOptions<AppOptions>>().Value;
Spring Boot DevTools — горячая перезагрузка

DevTools — ускоряет разработку:

  • Автоматическая перезагрузка при изменении кода
  • LiveReload — обновление браузера
  • Кэширование отключено в dev-режиме
  • Включается только в dev-профиле
// Подключение
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-devtools</artifactId>
    <scope>runtime</scope>
    <optional>true</optional>
</dependency>

// application.properties
spring.devtools.restart.enabled=true
spring.devtools.livereload.enabled=true

// Исключить изменения от перезагрузки
spring.devtools.restart.exclude=static/**,public/**

В C# аналог — Hot Reload (встроен в VS и dotnet watch):

dotnet watch run   # автоматическая перезагрузка
