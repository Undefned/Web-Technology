🧮 16. Алгоритмы. Структуры данных Mid+

Big O нотация — что это, примеры.
обяз

Big O — нотация для оценки сложности алгоритмов.

Обозначение Название Пример
O(1) Константная Доступ по индексу в массиве
O(log n) Логарифмическая Бинарный поиск, B-Tree
O(n) Линейная Проход по массиву
O(n log n) Линейно-логарифмическая Быстрая сортировка, слиянием
O(n²) Квадратичная Пузырьковая сортировка
O(2ⁿ) Экспоненциальная Факториал, перебор

Сложность коллекций .NET:

  • Dictionary — O(1) (средняя)
  • List.Add — O(1) амортизированно
  • List.Insert — O(n)
  • Array — O(1) по индексу
  • LinkedList — O(1) вставка, O(n) поиск
Бинарный поиск — суть, сложность, реализация.
обяз

Бинарный поиск — поиск в отсортированном массиве.

Сложность: O(log n)

Алгоритм:

  1. Найти средний элемент
  2. Если искомый < средний → искать слева
  3. Если искомый > средний → искать справа
  4. Повторять пока не найден

Реализация:

public int BinarySearch(int[] arr, int target)
{
    int left = 0;
    int right = arr.Length - 1;
    
    while (left <= right)
    {
        int mid = left + (right - left) / 2;  // Избегаем переполнения
        
        if (arr[mid] == target)
            return mid;
        else if (arr[mid] < target)
            left = mid + 1;
        else
            right = mid - 1;
    }
    
    return -1;  // Не найден
}

// Рекурсивная версия
public int BinarySearchRecursive(int[] arr, int target, int left, int right)
{
    if (left > right) return -1;
    
    int mid = left + (right - left) / 2;
    
    if (arr[mid] == target) return mid;
    if (arr[mid] < target) return BinarySearchRecursive(arr, target, mid + 1, right);
    return BinarySearchRecursive(arr, target, left, mid - 1);
}
Хэш-таблица — внутреннее устройство, сложность.
обяз

Хэш-таблица — структура данных для быстрого поиска по ключу.

Внутреннее устройство:

  • Массив buckets (корзин)
  • Хэш-функция преобразует ключ в индекс корзины
  • Коллизии разрешаются цепочками (linked list)
  • При переполнении размер увеличивается (rehashing)

Сложность:

  • Поиск, вставка, удаление: O(1) в среднем
  • Худший случай (коллизии): O(n)

Пример в C#:

dict.Add("key1", 42);

Коллизии хэшей — что это, методы разрешения.
mid

Коллизия — когда разные ключи дают одинаковый хэш-код.

Методы разрешения:

1. Цепочки (Chaining) — используется в .NET

  • Каждая корзина содержит список элементов
  • При коллизии элемент добавляется в список
  • Поиск — проход по списку (O(n) в худшем)

2. Открытая адресация (Open Addressing)

  • При коллизии ищем свободную корзину
  • Линейное, квадратичное или двойное хэширование
  • Удаление сложнее (нужны маркеры)

Как уменьшить коллизии:

  • Хорошая хэш-функция (равномерное распределение)
  • Большой размер таблицы (load factor)
  • Перехеширование при переполнении
  • В .NET load factor = 0.72 (при 72% заполнения — увеличение)
Рекурсия — что это, опасности (StackOverflow), хвостовая рекурсия.
обяз

Рекурсия — функция, которая вызывает саму себя.

Пример:

// Факториал рекурсивно
int Factorial(int n)
{
    if (n <= 1) return 1;  // Базовый случай
    return n * Factorial(n - 1);  // Рекурсивный случай
}

Опасности:

  • StackOverflowException — при глубокой рекурсии
  • Каждый вызов занимает стек (1 МБ)
  • Бесконечная рекурсия → падение

Хвостовая рекурсия (Tail Recursion):

  • Рекурсивный вызов — последняя операция
  • Компилятор может оптимизировать (не всегда)
  • В C# — только в .NET Framework (не в .NET Core)
// Хвостовая рекурсия
int FactorialTail(int n, int acc = 1)
{
    if (n <= 1) return acc;
    return FactorialTail(n - 1, n * acc);  // Последняя операция — вызов
}

Когда использовать:

  • Деревья, графы (обход)
  • Разделяй и властвуй (быстрая сортировка)
  • Когда глубина не превышает 100-1000

Альтернативы: итерация, стек, очередь.

Стек и Очередь — структуры, где применяются.
обяз

Стек (Stack) — LIFO (Last In, First Out)

  • Последний добавленный — первый извлечённый
  • Операции: Push, Pop, Peek
  • Применение: Undo/Redo, парсинг (скобки), DFS, вызовы функций
var stack = new Stack<string>();
stack.Push("Первый");
stack.Push("Второй");
Console.WriteLine(stack.Pop());  // "Второй"

Очередь (Queue) — FIFO (First In, First Out)

  • Первый добавленный — первый извлечённый
  • Операции: Enqueue, Dequeue, Peek
  • Применение: обработка задач, BFS, буферы, сообщения
var queue = new Queue<string>();
queue.Enqueue("Первый");
queue.Enqueue("Второй");
Console.WriteLine(queue.Dequeue());  // "Первый"
Односвязный vs Двусвязный список — разница.
mid

Односвязный список (Singly Linked List):

  • Каждый узел хранит данные + ссылку на следующий узел
  • Память: меньше (одна ссылка)
  • Обход: только вперёд
  • Удаление: нужно знать предыдущий узел

Двусвязный список (Doubly Linked List):

  • Каждый узел хранит данные + ссылки на следующий и предыдущий узлы
  • Память: больше (две ссылки)
  • Обход: вперёд и назад
  • Удаление: проще (есть ссылка на предыдущий)

В .NET:

  • LinkedList<T> — двусвязный список
  • Вставка/удаление в середине — O(1)
  • Доступ по индексу — O(n)
Деревья: бинарное дерево, AVL, красно-чёрное — базово.
mid

Бинарное дерево:

  • Каждый узел имеет до 2 детей (левый, правый)
  • Сложность поиска: O(log n) в среднем, O(n) в худшем

AVL-дерево (сбалансированное):

  • Баланс: разница высоты поддеревьев ≤ 1
  • Сложность: O(log n) всегда
  • Медленнее вставка/удаление (балансировка)

Красно-чёрное дерево (Red-Black Tree):

  • Сбалансированное дерево с цветами узлов (красный/чёрный)
  • Используется в .NET: SortedDictionary, SortedSet
  • Сложность: O(log n)
  • Быстрее вставка/удаление чем AVL

Применение в .NET:

  • Dictionary — хэш-таблица (не дерево)
  • SortedDictionary — красно-чёрное дерево
  • SortedSet — красно-чёрное дерево
Графы — обход в ширину (BFS) и в глубину (DFS) — суть.
mid

Граф — структура с вершинами (nodes) и рёбрами (edges).

BFS (Breadth-First Search) — обход в ширину

  • Использует очередь (Queue)
  • Сначала посещает все соседние вершины
  • Находит кратчайший путь (в невзвешенном графе)
  • Применение: поиск кратчайшего пути, социальные сети
void BFS(Graph graph, Node start)
{
    var visited = new HashSet<Node>();
    var queue = new Queue<Node>();
    queue.Enqueue(start);
    visited.Add(start);
    
    while (queue.Count > 0)
    {
        var node = queue.Dequeue();
        Console.WriteLine(node.Value);
        
        foreach (var neighbor in node.Neighbors)
        {
            if (!visited.Contains(neighbor))
            {
                visited.Add(neighbor);
                queue.Enqueue(neighbor);
            }
        }
    }
}

DFS (Depth-First Search) — обход в глубину

  • Использует стек (Stack) или рекурсию
  • Идёт как можно глубже, затем возвращается
  • Применение: поиск пути, топологическая сортировка, игры
void DFS(Graph graph, Node start)
{
    var visited = new HashSet<Node>();
    var stack = new Stack<Node>();
    stack.Push(start);
    
    while (stack.Count > 0)
    {
        var node = stack.Pop();
        if (visited.Contains(node)) continue;
        visited.Add(node);
        Console.WriteLine(node.Value);
        
        foreach (var neighbor in node.Neighbors)
        {
            if (!visited.Contains(neighbor))
                stack.Push(neighbor);
        }
    }
}
Сортировки: быстрая (QuickSort), слиянием (MergeSort).
mid

QuickSort (Быстрая сортировка):

  • Сложность: O(n log n) в среднем, O(n²) в худшем
  • Разделяй и властвуй
  • Выбирает опорный элемент (pivot)
  • Разбивает на меньшие и большие
  • Рекурсивно сортирует части
  • Используется в .NET: Array.Sort, List.Sort
void QuickSort(int[] arr, int left, int right)
{
    if (left >= right) return;
    int pivot = Partition(arr, left, right);
    QuickSort(arr, left, pivot - 1);
    QuickSort(arr, pivot + 1, right);
}

int Partition(int[] arr, int left, int right)
{
    int pivot = arr[right];
    int i = left - 1;
    for (int j = left; j < right; j++)
    {
        if (arr[j] <= pivot)
        {
            i++;
            (arr[i], arr[j]) = (arr[j], arr[i]);
        }
    }
    (arr[i + 1], arr[right]) = (arr[right], arr[i + 1]);
    return i + 1;
}

MergeSort (Сортировка слиянием):

  • Сложность: O(n log n) всегда
  • Разделяй и властвуй
  • Делит массив пополам
  • Рекурсивно сортирует половинки
  • Сливает отсортированные половинки
  • Стабильная сортировка
  • Требует дополнительной памяти O(n)
int[] MergeSort(int[] arr)
{
    if (arr.Length <= 1) return arr;
    int mid = arr.Length / 2;
    var left = MergeSort(arr[0..mid]);
    var right = MergeSort(arr[mid..]);
    return Merge(left, right);
}

int[] Merge(int[] left, int[] right)
{
    var result = new int[left.Length + right.Length];
    int i = 0, j = 0, k = 0;
    while (i < left.Length && j < right.Length)
        result[k++] = left[i] <= right[j] ? left[i++] : right[j++];
    while (i < left.Length) result[k++] = left[i++];
    while (j < right.Length) result[k++] = right[j++];
    return result;
}
