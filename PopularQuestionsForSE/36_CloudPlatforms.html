☁️ 36. Облачные платформы (Azure, AWS, Yandex Cloud) Mid+

Azure — основные сервисы для .NET разработчика.
mid

Microsoft Azure — облачная платформа от Microsoft, лидер для .NET.

Основные сервисы:

  • App Services — хостинг веб-приложений (.NET, Node.js, Python)
  • Azure Functions — Serverless (функции как сервис)
  • Azure SQL — управляемая БД SQL Server
  • Cosmos DB — глобально распределённая NoSQL БД
  • Azure Storage — Blob, Queue, Table, File
  • Azure Service Bus — брокер сообщений
  • Azure Key Vault — хранение секретов
  • Azure DevOps — CI/CD, репозитории
  • Application Insights — мониторинг и логирование

Пример деплоя в Azure App Service:

# Azure CLI
az webapp create --name MyApp --resource-group MyRG --plan MyPlan
az webapp deployment source config-zip --name MyApp --resource-group MyRG --src publish.zip

# GitHub Actions
- name: Deploy to Azure
  uses: azure/webapps-deploy@v2
  with:
    app-name: 'MyApp'
    publish-profile: ${{ secrets.AZURE_PUBLISH_PROFILE }}
    package: ./publish

Azure Functions (Serverless):

[FunctionName("ProcessOrder")]
public static async Task<IActionResult> Run(
    [HttpTrigger(AuthorizationLevel.Function, "post")] HttpRequest req,
    [Queue("orders")] IAsyncCollector<string> queue,
    ILogger log)
{
    string body = await new StreamReader(req.Body).ReadToEndAsync();
    await queue.AddAsync(body);
    return new OkResult();
}
AWS — основные сервисы для .NET разработчика.
mid

AWS (Amazon Web Services) — крупнейшая облачная платформа.

Основные сервисы:

  • EC2 — виртуальные машины (IaaS)
  • ECS / EKS — контейнеры (Docker / Kubernetes)
  • Lambda — Serverless (функции)
  • RDS — управляемые БД (PostgreSQL, MySQL, SQL Server)
  • DynamoDB — NoSQL (ключ-значение)
  • S3 — хранение файлов (Blob Storage)
  • SQS / SNS — очереди и уведомления
  • Secrets Manager — хранение секретов
  • CloudWatch — мониторинг и логи
  • CodePipeline / CodeDeploy — CI/CD

Пример деплоя в AWS Lambda:

// Amazon.Lambda.RuntimeSupport
public class Function
{
    public async Task<APIGatewayHttpApiV2ProxyResponse> FunctionHandler(
        APIGatewayHttpApiV2ProxyRequest request, ILambdaContext context)
    {
        return new APIGatewayHttpApiV2ProxyResponse
        {
            StatusCode = 200,
            Body = "Hello from Lambda!"
        };
    }
}

# AWS CLI
dotnet publish -c Release
aws lambda update-function-code --function-name MyFunction --zip-file fileb://publish.zip
Yandex Cloud — для российских компаний.
mid

Yandex Cloud — облачная платформа Яндекса (популярна в РФ).

Основные сервисы:

  • Compute Cloud — виртуальные машины
  • Managed Kubernetes — контейнеры
  • Serverless — функции, API Gateway
  • Managed Databases — PostgreSQL, MySQL, ClickHouse, MongoDB
  • Object Storage — S3-совместимое хранилище
  • Message Queue — очереди (аналог SQS)
  • Yandex Lockbox — хранение секретов
  • Yandex Monitoring — метрики и логи

Сравнение с Azure/AWS:

Сервис Azure AWS Yandex Cloud
ВМ Virtual Machines EC2 Compute Cloud
Хранилище Blob Storage S3 Object Storage
Serverless Functions Lambda Serverless Functions
БД Azure SQL, Cosmos DB RDS, DynamoDB Managed PostgreSQL, ClickHouse
Очереди Service Bus SQS Message Queue

Пример деплоя в Yandex Cloud (Serverless):

# yc — Yandex Cloud CLI
yc serverless function create --name my-function
yc serverless function version create \
    --function-name my-function \
    --runtime dotnetcore31 \
    --entrypoint Handler \
    --source-path ./publish.zip
S3 / Blob Storage — работа с файлами в облаке.
mid

Объектное хранилище — для хранения файлов (изображения, видео, бэкапы).

Azure Blob Storage:

// Azure.Storage.Blobs
var container = new BlobContainerClient(connectionString, "mycontainer");
await container.CreateIfNotExistsAsync();

// Загрузка
var blob = container.GetBlobClient("image.jpg");
await blob.UploadAsync(stream);

// Скачивание
var response = await blob.DownloadAsync();
var stream = response.Value.Content;

AWS S3:

// AWSSDK.S3
var client = new AmazonS3Client(accessKey, secretKey, RegionEndpoint.EUCentral1);

// Загрузка
await client.PutObjectAsync(new PutObjectRequest
{
    BucketName = "mybucket",
    Key = "image.jpg",
    InputStream = stream
});

// Скачивание
var response = await client.GetObjectAsync(new GetObjectRequest
{
    BucketName = "mybucket",
    Key = "image.jpg"
});
var stream = response.ResponseStream;
