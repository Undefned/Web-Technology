System.Text.Json vs Newtonsoft.Json.
mid
Характеристика System.Text.Json Newtonsoft.Json
Производительность Быстрее (в 2-3 раза) Медленнее
Память Меньше (Span, Utf8) Больше
Функции Базовые Богатые (линки, конвертеры)
Атрибуты JsonPropertyName, JsonIgnore JsonProperty, JsonIgnore
Полиморфизм Сложнее Легче (JsonSubTypes)
Где использовать ASP.NET Core (по умолчанию) Устаревшие проекты, сложные сценарии

Пример System.Text.Json:

var options = new JsonSerializerOptions
{
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
    WriteIndented = true
};

string json = JsonSerializer.Serialize(user, options);
var user = JsonSerializer.Deserialize<User>(json, options);
Атрибуты сериализации — JsonIgnore, JsonPropertyName.
mid 
public class User
{
    public int Id { get; set; }

    [JsonPropertyName("fullName")]
    public string Name { get; set; }

    [JsonIgnore]
    public string PasswordHash { get; set; }

    [JsonConverter(typeof(DateTimeConverter))]
    public DateTime CreatedAt { get; set; }
}

// Атрибуты для Newtonsoft.Json
public class User
{
    [JsonProperty("id")]
    public int Id { get; set; }

    [JsonProperty("full_name")]
    public string Name { get; set; }

    [JsonIgnore]
    public string PasswordHash { get; set; }
}
Полиморфная сериализация.
mid

System.Text.Json (C# 11+):

[JsonDerivedType(typeof(Circle), typeDiscriminator: "circle")]
[JsonDerivedType(typeof(Rectangle), typeDiscriminator: "rectangle")]
public abstract class Shape { }

public class Circle : Shape { public double Radius { get; set; } }
public class Rectangle : Shape { public double Width { get; set; } public double Height { get; set; } }

// Сериализация
var shapes = new List<Shape> { new Circle { Radius = 5 }, new Rectangle { Width = 10, Height = 20 } };
string json = JsonSerializer.Serialize(shapes);
// [{"$type":"circle","Radius":5},{"$type":"rectangle","Width":10,"Height":20}]

Newtonsoft.Json:

[JsonConverter(typeof(JsonSubtypes))]
[JsonSubtypes.KnownSubType(typeof(Circle), "circle")]
[JsonSubtypes.KnownSubType(typeof(Rectangle), "rectangle")]
public abstract class Shape { }
XML-сериализация (XmlSerializer, DataContractSerializer).
mid

XmlSerializer:

[XmlRoot("User")]
public class User
{
    [XmlElement("Id")]
    public int Id { get; set; }

    [XmlElement("Name")]
    public string Name { get; set; }

    [XmlIgnore]
    public string PasswordHash { get; set; }
}

// Сериализация
var serializer = new XmlSerializer(typeof(User));
using var sw = new StringWriter();
serializer.Serialize(sw, user);
string xml = sw.ToString();

// Десериализация
using var sr = new StringReader(xml);
var user = (User)serializer.Deserialize(sr);

DataContractSerializer:

[DataContract]
public class User
{
    [DataMember]
    public int Id { get; set; }

    [DataMember]
    public string Name { get; set; }
}
Protobuf — для gRPC, бинарная сериализация.
mid

Protobuf (Protocol Buffers) — бинарный формат от Google.

.proto файл:

syntax = "proto3";

message User
{
    int32 id = 1;
    string name = 2;
    string email = 3;
}

В .NET:

// Генерация классов из .proto
// dotnet add package Google.Protobuf
// dotnet add package Grpc.Tools

var user = new User { Id = 1, Name = "Alice", Email = "alice@example.com" };

// Сериализация
byte[] data = user.ToByteArray();

// Десериализация
var user2 = User.Parser.ParseFrom(data);

Преимущества Protobuf:

  • Меньший размер (бинарный)
  • Быстрее чем JSON
  • Строгая типизация
  • Поддерживает стриминг
