🧪 10. Тестирование в Java — особенности

JUnit 5 vs TestNG — разница

JUnit 5 — стандарт для Java. TestNG — альтернатива (особенно в TestNG-проектах).

ХарактеристикаJUnit 5TestNG
Аннотации@Test, @BeforeEach, @AfterEach@Test, @BeforeMethod, @AfterMethod
Группировка@Taggroups
Зависимости@TestInstancedependsOnMethods
Параметризация@ParameterizedTest + @CsvSource@DataProvider
// JUnit 5
@Test
void testAdd() {
    assertEquals(5, calculator.add(2, 3));
}

@ParameterizedTest
@CsvSource({"1,2,3", "4,5,9", "10,20,30"})
void testAddParameterized(int a, int b, int expected) {
    assertEquals(expected, calculator.add(a, b));
}

// TestNG
@Test
void testAdd() {
    Assert.assertEquals(calculator.add(2, 3), 5);
}

@DataProvider(name = "addData")
public Object[][] data() {
    return new Object[][]{{1,2,3}, {4,5,9}, {10,20,30}};
}

@Test(dataProvider = "addData")
void testAddParameterized(int a, int b, int expected) {
    Assert.assertEquals(calculator.add(a, b), expected);
}
Mockito vs PowerMock — разница

Mockito — стандартный мок-фреймворк. PowerMock — расширение для статических методов, конструкторов, private-методов.

// Mockito — обычное мокирование
@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    @Mock
    private UserRepository repository;
    
    @InjectMocks
    private UserService service;
    
    @Test
    void testFindUser() {
        when(repository.findById(1L)).thenReturn(Optional.of(new User("John")));
        
        User user = service.findUser(1L);
        assertEquals("John", user.getName());
    }
}

// Mockito + PowerMock (для статики)
@RunWith(PowerMockRunner.class)
@PrepareForTest({StaticService.class})
class StaticTest {
    @Test
    void testStaticMethod() {
        PowerMockito.mockStatic(StaticService.class);
        when(StaticService.getData()).thenReturn("Mocked");
        
        assertEquals("Mocked", StaticService.getData());
    }
    
    @Test
    void testPrivateMethod() throws Exception {
        UserService service = new UserService();
        UserService spy = spy(service);
        
        doReturn("Mocked").when(spy, "privateMethod");
        // ...
    }
}

В C# аналог — Moq + (для статики — ShimContext в MSTest или просто не использовать статику).

@DataJpaTest, @WebMvcTest, @SpringBootTest — разница

Аннотации для разных уровней интеграционного тестирования.

  • @DataJpaTest — только JPA-слой (репозитории). In-memory БД.
  • @WebMvcTest — только Web-слой (контроллеры). Mock-объекты.
  • @SpringBootTest — полный контекст (всё приложение).
// @DataJpaTest — только репозитории
@DataJpaTest
class UserRepositoryTest {
    @Autowired
    private UserRepository repository;
    
    @Test
    void testFindByEmail() {
        User user = new User("john@mail.com");
        repository.save(user);
        
        Optional<User> found = repository.findByEmail("john@mail.com");
        assertTrue(found.isPresent());
    }
}

// @WebMvcTest — только контроллеры (с моками)
@WebMvcTest(UserController.class)
class UserControllerTest {
    @Autowired
    private MockMvc mockMvc;
    
    @MockBean
    private UserService service;
    
    @Test
    void testGetUser() throws Exception {
        when(service.findUser(1L)).thenReturn(new User("John"));
        
        mockMvc.perform(get("/users/1"))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.name").value("John"));
    }
}

// @SpringBootTest — полный контекст
@SpringBootTest
@AutoConfigureTestDatabase(replace = AutoConfigureTestDatabase.Replace.NONE)
class IntegrationTest {
    @Autowired
    private UserController controller;
    
    @Test
    void testFullFlow() {
        // работает с реальным контекстом
    }
}

@Testcontainers — тестирование с реальной БД

Testcontainers — запуск Docker-контейнеров для тестов (БД, Redis, Kafka).

// Подключение
<dependency>
    <groupId>org.testcontainers</groupId>
    <artifactId>testcontainers</artifactId>
    <version>1.19.0</version>
    <scope>test</scope>
</dependency>

// PostgreSQL контейнер
@Testcontainers
@DataJpaTest
class UserRepositoryTest {
    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:15")
        .withDatabaseName("testdb")
        .withUsername("test")
        .withPassword("test");
    
    @Test
    void testWithRealDB() {
        // Работает с реальным PostgreSQL в Docker
    }
}

// Кастомный контейнер (Redis)
@Container
static GenericContainer<?> redis = new GenericContainer<>("redis:7")
    .withExposedPorts(6379);

// Kafka контейнер
@Container
static KafkaContainer kafka = new KafkaContainer(DockerImageName.parse("confluentinc/cp-kafka:latest"));

@Test
void testWithKafka() {
    String bootstrapServers = kafka.getBootstrapServers();
    // используем в тесте
}
